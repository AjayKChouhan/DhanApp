How order detection works

Dhan's Live Order Update WebSocket documentation says an individual account receives updates for orders placed through any platform. This includes orders placed in Dhan's app. The API monitors the configured master and copies supported BUY/SELL order types to enabled children. Bracket/cover, after-market, and disclosed-quantity orders are reported as unsupported rather than silently altered.

Copying only runs while this API is online and connected. Each observed master order is recorded once; child orders use a stable correlation ID and the order status stream to suppress repeats. Dhan documents correlation IDs for tracking, not as an exactly-once guarantee; a network failure at submission time can still be ambiguous. Copying does not guarantee matching execution prices, fills, available funds, or that Dhan will accept every child order.
