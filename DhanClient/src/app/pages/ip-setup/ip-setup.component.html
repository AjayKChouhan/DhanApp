Setup Static IP

Dhan requires order placement/modification/cancellation to come from a whitelisted static IP (per account, not per computer). This auto-detects this server's own public IP - the IP Dhan actually sees when this app places orders - so you don't need to look it up or type it manually. It then sets that same IP for every saved account in one click. Once set, an IP cannot be changed again for 7 days.
